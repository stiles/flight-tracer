# Mapbox logo

`mapbox-logo.png` is Mapbox's official black icon and wordmark, cropped from
the surrounding explanatory labels in its brand-guidelines illustration.
The logo itself is unchanged. It remains a Mapbox trademark and is not
covered by this project's CC0 dedication.
